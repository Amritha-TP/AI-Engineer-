About CIFAR-10 Dataset

The CIFAR-10 dataset is an established benchmark in computer vision maintained by the Canadian Institute For Advanced Research. It consists of 60,000 32x32 color images across 10 mutually exclusive categories:

✈️ Airplane 🚗 Automobile 🐦 Bird 🐱 Cat 🦌 Deer 🐶 Dog 🐸 Frog 🐴 Horse 🚢 Ship 🚚 Truck
Model Specifications
  • Architecture: Deep Convolutional Neural Network
  • Input Dimension: 32 × 32 × 3 RGB
  • Layers: Conv2D → BatchNorm → ReLU → MaxPool → Dropout → Softmax
  • Optimizer: Adam (Categorical Crossentropy)
  • Interpretability: Integrated Grad-CAM Heatmap
