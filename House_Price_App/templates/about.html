About This Project

EstatePredict is a modern, responsive web application designed to predict house prices using Deep Learning.

How It Works

The application dynamically loads a pre-trained Keras model (.h5) from the server. It inspects the model's architecture to automatically generate the correct number of input fields for the user. When submitted, the input data is preprocessed, reshaped, and fed into the model to produce a final estimated price.

Tech Stack
  • Backend: Python, Flask, TensorFlow/Keras, NumPy, Pandas
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
